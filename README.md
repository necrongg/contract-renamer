# 근로계약서 파일명 변경기

근로계약서 스캔 PDF와 이미지에서 팀장명·사용자명을 인식해 파일명을 일괄 변경하는 Windows 프로그램입니다.

## 주요 기능

- OCR 파일명 변경, 진행률 표시, 작업 중단 및 TXT 로그 저장
- Excel 검증과 수기 파일명 수정
- 열려 있는 PDF의 이름 변경을 자동 재시도
- Shift로 여러 PDF를 선택하고 Enter로 한 번에 열기

## 실행과 인증

배포용 ZIP은 담당자에게 별도로 제공받으세요. 압축을 해제한 뒤 EXE와 `_internal` 폴더를 함께 두고 실행합니다. OCR에는 Windows용 Tesseract와 한국어 `kor` 언어 데이터가 필요합니다. 최초 실행 시 PC 인증 ID가 표시되며, 관리자에게 180일 인증 코드를 요청해야 합니다.

사용법은 [사용법.md](사용법.md)를 참고하세요.
